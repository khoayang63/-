# E-Commerce Application

A modern, full-stack e-commerce application built with Next.js App Router and Supabase.

## Features
- **Authentication**: Secure user login/signup using Supabase Auth.
- **Product Catalog**: Browse figures by series, handle pre-orders and available stock.
- **Cart & Checkout**: Context-based cart state synchronized with database.
- **Voucher System**: Support for percentage, fixed amount, and shipping vouchers.
- **Dynamic Shipping Calculation**: Geocoding via Nominatim and distance routing via OSRM to auto-calculate shipping fees based on distance.
- **Payment Processing**: Cash on Delivery (COD) and Online Payment (QR Code via SePay).
- **Responsive Design**: Built with Tailwind CSS, fully responsive, and features a premium dark theme.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Database & Auth**: Supabase (PostgreSQL)
- **Styling**: Tailwind CSS
- **Icons**: React Icons
- **Toast Notifications**: React Hot Toast
